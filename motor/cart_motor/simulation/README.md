# cart_motor 오프라인 시뮬레이션

실행: 저장소 루트에서 `MPLCONFIGDIR=/tmp/cart_motor_mpl python3 motor/cart_motor/simulation/simulate.py`

Python 3와 matplotlib이 필요합니다. ROS 2, pyserial, minimalmodbus나 실제 모터는 필요하지 않습니다.
별도 프로세스로 실행하세요. 스크립트가 프로세스 내부의 ROS/통신 모듈을 가짜 구현으로 대체합니다.

실제 `simple_motor.py`, `motor_driver.py`, `motor_config.py`를 불러오고,
ROS 메시지·노드와 Modbus 레지스터 장치만 대체합니다. 원래 운전 코드는 수정하지 않습니다.
기본 시나리오는 시작 위치 10000 unit, 종료 위치 55000 unit(간격 30 mm)을 명시적으로 지정합니다.
실제 프로그램은 사용자가 motor_config.py 상단의 START_POS, END_POS를 지정해야 하며 현재 위치로 덮어쓰지 않습니다.

모델은 레지스터에 기록된 속도 및 가감속으로 1 ms 이하 간격의 이상적인 운동을 계산합니다.
코드의 sleep은 가상 시간으로 반영하고, 통신 지연·ROS 스케줄링 지연·부하·중력·실제 펌웨어는 모델링하지 않습니다.
정지 레지스터는 즉시 정지로 가정합니다. 따라서 실제 정지 거리나 정지 성능을 검증하지 않습니다.
전류 및 fault는 물리 계산 대신 시나리오에서 주입합니다.

정상 왕복, 전진 도중 복귀, 긴급정지, 연속 과전류, 드라이버 fault, 이동 시간 초과,
목표 위치 제한 초과, 위치 미설정, 도착 범위 중첩, 감소 방향 왕복, 시작점 밖에서의 복귀까지
11개 시나리오의 최종 상태를 assertion으로 확인합니다.
설정 오류가 연결 전에 차단되는지, setup 시 자동 이동하지 않는지, 시작점 밖에서 전진이 무시되는지도 확인합니다.
정상 왕복 및 중도 복귀는 시작점 도달도 확인합니다.

출력: `results.json`에 상태 전환 및 오류, 각 CSV에 시간·상대 위치·상태,
`motion.png`에 정상 왕복·중도 복귀·긴급정지 그래프를 저장합니다.
시간은 setup 완료 기준입니다(설정 중 오류 시에는 setup 시작 기준).
상태 전환 시간은 tick 종료 시 관측한 시각이므로 내부 sleep 시간이 포함됩니다.
